# 🏬 地下商业街智能导航系统

顾客选择**地铁口 / 店铺 / 服务台 / 停车场**作为起终点，系统综合
**楼层、扶梯、电梯、通道距离、营业状态**规划最短时间路径，并输出分段步行指引。

## 核心规则

- 图模型：节点 = POI/扶梯/电梯/通道节点；边 = 通道 / 扶梯 / 电梯。
- 权重（Dijkstra 最短时间）：
  - 通道：距离 ÷ 75 m/min
  - 扶梯：层高(6m) ÷ 30 m/min（约 12 秒/层）
  - 电梯：等待 30 秒 + 层高 ÷ 30 m/min（约 42 秒/层）
- **未营业的店铺不能作为终点**（`open=false` 歇业/装修，或当前时间不在营业时间内）。
- 未营业店铺**可以作为起点**（顾客从店门口离开），且寻路时**不会借道穿过**闭店。
- 营业时间支持跨午夜（如海底捞 `11:00-02:00`）与 24 小时（`00:00-24:00`）。


## 测试

```bash
python -m pytest tests/ -v
```

覆盖：图结构完整性、营业时间边界/跨午夜/24h、闭店终点拦截、闭店起点放行、
闭店不被借道、跨层选扶梯/电梯、耗时一致性、步行距离统计、API 错误码等 29 个用例。

## API

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/map?now=HH:MM` | 楼层、节点（含实时营业状态）、边 |
| POST | `/api/route` | body: `{"start","end","now":"HH:MM"}`，返回节点链、边链、楼层、距离、耗时、分段指引 |

错误码：`destination_closed` / `unknown_node` / `same_point` / `invalid_time` / `no_route`（HTTP 400）。

## 前端演示页面（`/`）

- 起终点下拉选择（按楼层分组，闭店在终点下拉中自动禁用）
- 可调整**模拟时间**（含清晨/中午/深夜/凌晨快捷按钮）实时刷新营业状态
- SVG 分层地图：B1/B2/B3 楼层切换、通道/扶梯/电梯不同线型、闭店置灰删除线
- 规划路线红色动画高亮、起终点圆环、点击地图图标快速设为终点
- 路线概览：步行距离、总耗时、途经楼层、换乘次数、扶梯/电梯段数
- 分段中文指引（含通道转向提示、乘梯楼层与耗时）
